# Claude Code instructions

Read and follow [`AGENTS.md`](./AGENTS.md) before planning or editing. It is the canonical repository instruction file; [`docs/agent-playbook.md`](./docs/agent-playbook.md) contains the detailed repository map and validation workflow.

In particular:

- treat `ROADMAP.md` as live status and `TECHNICAL_REVIEW.md` as a historical snapshot;
- preserve the Chrome 35/webOS compatibility target;
- reproduce playback defects in focused tests or loader-boundary scenarios where possible;
- never upgrade device-only evidence to a completed claim without an LG TV observation;
- keep diagnostics free of full URLs, tokens, cookies, and personal viewing data.
